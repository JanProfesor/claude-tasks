Privacy policy

Last updated: 19-11-2026

Claude Tasks is a personal tool used only by its developer, Jan Pawlik, on his own Google account.

Data accessed

With the user's consent the app uses the Google Tasks API (scope https://www.googleapis.com/auth/tasks) to list, create, update and complete tasks and task lists in the signed-in account. It accesses no other Google data.

Storage and sharing

The OAuth token is stored only on the developer's own computer. Task data is not sold, shared with third parties, or used for advertising. It is processed only to carry out the user's own requests.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
